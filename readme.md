# 🤖 CubeBot - Companion Robot Control Panel

A complete web dashboard for controlling the CubeBot companion robot. Features user authentication, robot mode control, weather display, pomodoro timer, and alarm system.

## ✨ Features

- 🔐 **User Authentication** - Login/Register with Supabase
- 🎮 **Robot Control** - Change facial expressions and modes
- 🌤️ **Weather Display** - Real-time Manila weather
- ⏲️ **Pomodoro Timer** - Focus timer with display on robot
- ⏰ **Alarm System** - Set alarms with buzzer notification
- 📱 **Responsive Design** - Works on mobile and desktop

## 🚀 Quick Start
